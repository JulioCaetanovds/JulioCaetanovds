### 🚀 Projetos em Destaque

#### 1. [QA Automation] [Rubeus - Teste de Alta Performance](https://github.com/JulioCaetanovds/rubeus-teste-qa)
> **Stack:** Python 3.14, Playwright, Pytest, Faker.
Uma suíte de testes E2E moderna que demonstra maturidade técnica.
- **Diferenciais:** Uso de lógica **XFAIL** para mapeamento de bugs conhecidos, geração de massa de dados dinâmica com Faker e testes de responsividade mobile.

#### 2. [SDET/Mobile] [GhostTouch QA - Native Driver PoC](https://github.com/JulioCaetanovds/GhostTouch-QA-Automation)
> **Stack:** Flutter, Kotlin, Android Native Bridge (Accessibility Service).
Uma Prova de Conceito (PoC) de um driver de automação "Black-box".
- **Diferenciais:** Implementação de um **Native Bridge** em Kotlin para controlar o Android Accessibility Service, permitindo automação em apps de terceiros sem acesso ao código-fonte.

#### 3. [QA Automation] [Ruby Web Automation - BugBank](https://github.com/JulioCaetanovds/AutomacaoTestes-Ruby_2.0)
> **Stack:** Ruby, Cucumber, Capybara, Selenium.
Automação web clássica com foco em BDD e robustez.
- **Diferenciais:** Execução de testes em paralelo e cobertura completa de fluxos financeiros (registro, login, transferências).
